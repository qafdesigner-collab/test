# Perfume ERP implementation

Single-company Laravel installations with separate databases. This project implements business workflows incrementally from the complete development prompt.

## Planned core

- Session login, CSRF protection, user roles and company settings.
- Image catalogue, scent classification, internal inspiration directory, units and prices.
- Inventory ledger with lot/location balances and controlled receipts/adjustments.
- Customer/supplier directory and wholesale quotation/order/invoice workflow.
- Retail POS with transaction idempotency, stock checks, shifts and returns.
- Confidential versioned formulas and production: issue, maturation, QC, actual output.
- Artwork/project approval and packaging/printing job tracking.
- Operational dashboards, exports, backups and audit history.

## Release boundary

An operational development build is not commercial acceptance. Hybrid branch replication, provider-connected UAE electronic invoicing, payment-terminal drivers, a full accounting engine, Arabic translation, signed vendor licence infrastructure and production deployment hardening require their own verified releases. Unsupported features must be clearly identified in the interface and documentation, never simulated.

## Interface

Ivory canvas, navy sidebar, restrained burgundy accent, product photography/illustrations, readable operational tables, clear forms and responsive navigation. No CDN dependency for ordinary operation on a LAN.
